# Prompt — Discuss the Idea

Paste this into your AI chat:

```text
I am starting a new software project using a guided small-slice workflow.

Do not write implementation code yet.

Help me turn my rough idea into a clear project definition. Ask useful questions one small group at a time. Focus on:
- what I want to build;
- who it is for;
- the first useful user outcome;
- required vs optional features;
- what should be excluded from v0.1;
- target devices/platforms;
- existing tools/repos/designs I want to reuse;
- constraints or preferences that could affect architecture.

Do not invent requirements when I have not decided them. Point out important unanswered questions. Once we agree the idea is clear, summarize the decisions in a form that can be used to fill docs/00_IDEA.md.
```
